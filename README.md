# どっち撃つねん

SNS の広告動画でよく見る「敵の大群と強化アイテムが同時に流れてくるシューティング」を、ちゃんと遊べるブラウザゲームにしたものです。

遊ぶ: https://ttk1.github.io/docchi-utsunen/

道の真ん中を「現代人のストレス」（未読通知、迷惑メール、締切、リボ払い）が押し寄せ、左右の端を強化ブロックが流れていきます。左右に動いて、正面だけを撃てます。敵を撃てば安全、強化を撃てば将来が楽になります。水鉄砲から始めて、どこまで行けるでしょうか。

## 遊び方

| 環境 | 操作 |
| --- | --- |
| スマホ | 画面に触れた横位置へ動く。なぞると付いてくる |
| PC | マウスを動かした横位置へ動く。← → または A D キーでも動ける（押している間だけ）。Esc か P で一時停止 |

- 射撃は自動で、正面にまっすぐ飛びます。動く速さには上限があるので、道の端から端まで 0.6 秒かかります。
- 敵の真ん中を捉えると「会心」で、ダメージが 2 倍になります。ボスの弱点（的の印）は左右に動くので、追いかけてください。
- 道が敵で埋まる（埋まり度 100%）とゲームオーバーです。
- 強化ブロックは左右に 1 個ずつ、2 個 1 組で流れてきます。通り過ぎる前に壊し切ると効果が出ます。数字が白なら、今から向かえば間に合います。赤なら間に合いません。両方壊せば「両取り」です。
- 敵は種類ごとに割のよさが違います。かたまった迷惑メールはまとめて倒せ、リボ払いは育つ前に倒すのが得で、締切は硬いうえに後ろの敵の盾になります。
- 20 秒ごとにラッシュが来ます。5 ウェーブごとにボスが出ます。
- 遊び進めるほど、景色が昼 → 夕焼け → 夜 → 夜明けと変わります。
- 残るのはハイスコアだけです。永続強化も課金もありません。タイトルの「ショップ」は、それらしく見えるだけのネタです（お金はかからず、入力するものもなく、強くもなりません）。

## 開発

Docker で動かします（Node や Python はホストに入れません）。

```sh
docker compose up                                 # 開発サーバー → http://localhost:5173/
docker compose run --rm test                      # 単体テスト
docker compose run --rm sim                       # バランス検証（最後に「総合: 合格」と出れば成功）
docker compose run --rm check                     # 型検査
docker compose run --rm build                     # dist/ に静的ファイルを出力
docker compose run --rm --service-ports preview   # dist/ を配信 → http://localhost:4173/
docker compose run --rm reference                 # Python の参照シミュレータ（最後に「総合: 合格」と出れば成功）
```

`dist/` の中身は、そのまま静的ファイルとして配信できます（サブパスに置いても動きます）。
